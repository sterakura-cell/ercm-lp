# ERCM/OHD 販売パートナーLP

内熱型熱分解装置 ERCM／油化装置 OHD の販売パートナー用ランディングページ。本番: https://ercm.soter-info.com

## 構成
- **ビルド工程なし**。`index.html` 1枚に HTML/CSS/JS が全部入り。npm依存もフレームワークも無い。
- ホスティングは GitHub Pages（`main` push で自動デプロイ）。
- CVは「4問の適合診断 → 個別試算依頼フォーム」。診断回答はフォーム送信に自動添付される。
